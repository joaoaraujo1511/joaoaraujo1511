### What I'm working on

- **Backend with Elixir & Phoenix**: real-time web applications with Phoenix LiveView, WebSockets and PostgreSQL.
- **Automated data pipelines**: web scraping and API integrations that keep application data current without manual work.
- **Self-hosted infrastructure**: a Raspberry Pi 5 home lab running production services with Docker and Cloudflare Tunnel.
